# IONHealthFitnessLib

A library for accessing Android Health Connect data for health and fitness apps.

## Installation

### Gradle

> Replace ${version to use} below with the version you want to use. Check the Releases page for available versions.

Add the following to your module's `build.gradle` file:

```groovy
dependencies {
    implementation 'io.ionic.libs:ionhealthfitness-android:${version to use}'
}
```

Make sure you have the appropriate Maven repository declared in your project-level `build.gradle` or `settings.gradle`:

```groovy
repositories {
    google()
    mavenCentral()
}
```
